This addon lets a project manager enable Scrum for an individual Project.
From that project's form, use the sprint action to create and manage sprints
with a name, dates, members, project, and goal. Issues can be assigned to a
planned or active sprint from their form or list.

The Odoo 19 port keeps sprints project-specific. Sprints cannot be enabled
for ordinary projects, a project can have only one active sprint, and an
active sprint cannot be completed while unfinished issues remain in it. Move
each unfinished issue to the backlog or another planned sprint first. Sprint
dates, members, project, and goal are locked after start. Timelines are not
part of this core port.
