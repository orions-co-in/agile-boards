Agile Version

Releases building block of Agile Boards for Odoo 19 and 20.

What it is

This add-on provides versions and releases on project tasks, which Agile Boards uses for fix versions, releases and release notes. It is installed automatically when you install Agile Boards (agile_community), so you do not need to install it yourself, and on its own it adds nothing a user needs to learn.

Where to start

Install Agile Boards from the Apps list. This module is a part of it, based on open-source work from the Odoo Community Association, and is released under AGPL-3.
